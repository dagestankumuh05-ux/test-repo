## MiniCraft — лёгкая тестовая версия Minecraft для Android

Простая voxel-игра в духе Minecraft на Three.js, которая запускается прямо
в браузере (Chrome на Android) — без сборки APK и без Android Studio.
Это самый лёгкий способ быстро протестировать идею на телефоне.

### Что внутри
- `index.html` — вся игра (сцена, управление, логика мира) одним файлом.
- `vendor/three.min.js` — локальная копия Three.js, так что игра работает
  полностью офлайн, без интернета и без CDN.

### Возможности
- Процедурно генерируемый небольшой voxel-мир (трава, земля, камень, немного «деревьев»).
- Ходьба с гравитацией и прыжком.
- Разрушение и установка блоков (5 типов блоков в хотбаре).
- Управление под тач-экран: слева — виртуальный джойстик для движения,
  справа — свайп для поворота камеры, справа снизу — кнопки прыжка,
  разрушения (⛏) и установки (＋) блока.

### Как запустить на Android
1. Скопируйте папку с игрой на телефон (или разместите репозиторий на
   GitHub Pages / любом статическом хостинге).
2. Откройте `index.html` в Chrome на Android (либо через локальный сервер,
   например `python3 -m http.server`, и зайдите на `http://<ip>:8000`).
3. Нажмите «Играть» и разрешите полноэкранный режим для лучшего теста.

### Как запустить локально для разработки
```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000/index.html в браузере
```

Это тестовая/учебная версия — без сохранения мира, без крафта и мобов,
чтобы быстро проверить основную механику на Android.
